# Проверки WiFi Studio

## Автоматические проверки

Соберите проект и выполните проверки в обеих конфигурациях:

```powershell
ctest --preset release
```

```powershell
ctest --preset debug
```

Проверяются границы SSID и пароля, управляющие/не-ASCII символы, сочетания диапазона и защиты, генератор паролей и выбор языка. SSID — 1–32 печатных ASCII-символа, не только пробелы; пароль — 8–63.

## Язык интерфейса

При обычном запуске используется `GetUserDefaultUILanguage`: русский язык интерфейса Windows выбирает русский, любой другой — английский. Регион и формат даты на выбор не влияют. Язык общий для интерфейса и фонового сетевого потока.

Для проверки без смены языка Windows доступны `--lang ru` и `--lang en` в GUI и CLI. Пользовательские имена подключений и адаптеров, названия устройств и сообщения, возвращаемые самой Windows, не переводятся приложением.

Проверка реального окна без включения сети:

```powershell
pwsh -NoProfile -File tools/Test-Gui.ps1 -Language en -Screenshot out/artifacts/gui-en.png
```

```powershell
pwsh -NoProfile -File tools/Test-Gui.ps1 -Language ru -Screenshot out/artifacts/gui-ru.png
```

Без `-Language` проверяется автоматический выбор по Windows. Скрипт проверяет перевод, перечисление адаптеров, маскировку пароля, генерацию и обновление. Пароль не считывается. Снимки сохраняются в `out/artifacts`; `-LeaveOpen` оставляет окно открытым.

Проверка закрытия во время инициализации, компактного окна и вертикальной прокрутки:

```powershell
pwsh -NoProfile -File tools/Test-WindowLayout.ps1 -Language en
```

Перед GUI-тестами закройте другие экземпляры WiFi Studio.

## Диагностика без изменения сети

```powershell
.\out\build\vs2026-x64\Release\wifi-hotspot-cli.exe --diagnose --lang en
```

Команда не включает точку доступа и не сканирует соседние сети. Если Windows видит адаптер через Native WLAN, но не предоставляет WinRT-доступ, проверьте разрешения геолокации / Wi-Fi и административные политики. Приложение не изменяет реестр, разрешения, службы, ICS или брандмауэр.

## Тесты с реальным включением точки доступа

Проводите их только на доступном для тестирования адаптере. Не запускайте одновременно другие программы управления хот-спотом. Активная чужая сессия не останавливается и не перенастраивается.

```powershell
.\out\build\vs2026-x64\Release\wifi-hotspot-cli.exe --test-cycle --band 2.4 --security wpa3
```

CLI требует состояние `Off`, создаёт временную защищённую сеть на пять секунд, проверяет `On`, останавливает её до `Off` и сравнивает сохранённую конфигурацию Windows до/после только в памяти. Пароль не выводится. При нескольких адаптерах укажите `--adapter GUID` из диагностики. Доступны `--source GUID`, `--band auto|2.4|5|6`, `--security wpa2|wpa3|transition`.

Проверка реальных кнопок GUI:

```powershell
pwsh -NoProfile -File tools/Test-Gui.ps1 -HardwareCycle -Security wpa3 -Language en
```

Для переходного режима укажите `-Security transition`; по умолчанию аппаратный GUI-тест использует WPA2. Скрипт также проверяет отказ второго процесса вмешиваться в активную сессию.

## Фактически проверено 2026-11-22

На тестовой Windows 11:

- Release / Debug и автономные тесты; нативное окно, маскировка пароля, генерация, обновление.
- Запуск и остановка на физическом USB Wi-Fi-адаптере: **2,4 ГГц / WPA2**, а после обновления драйвера — **WPA3** и **WPA2/WPA3 transition** через CLI и GUI.
- Сохранённая конфигурация Windows после CLI-циклов не изменилась.
- Второй процесс отказывается менять активный хот-спот.
- Закрытие во время инициализации не показывает модальное окно ожидания.
- Прокрутка окна 960×660 логических пикселей при DPI 144 (150%).

Подробности защиты: [WPA3.md](WPA3.md). Доступность диапазонов и защиты определяется Windows и драйвером, а не названием или клиентскими возможностями устройства.

## Проверка вторым устройством

Эти пункты **не проверены** без отдельного физического клиента:

- Видимость заданного SSID и подключение с правильным паролем.
- Отказ при неправильном пароле, фактическая WPA3/SAE-аутентификация.
- DHCP-адрес, связь с хостом и Интернет через выбранный источник.
- Обновление списка клиентов при подключении и отключении.
- Работа 5 / 6 ГГц на совместимом оборудовании.

## Поведение при сбоях

- Активный чужой хот-спот: только наблюдение.
- Отсутствие адаптера или источника: запуск недоступен; выбранный адаптер не подменяется другим.
- Ошибки политики, радио или драйвера: сообщение Windows, без обхода ограничений и автоматического понижения защиты.
- Закрытие своей сессии: подтверждение, остановка, выход. Если выключение не подтверждено, окно остаётся открытым.
- Аварийное завершение или потеря питания не гарантируют очистку: проверьте Mobile Hotspot в параметрах Windows.
