# WiFi Studio

Нативное приложение на C++20 для мобильной точки доступа Windows 11. Позволяет выбрать Wi-Fi-адаптер и источник Интернета, задать имя сети, пароль, диапазон и защиту WPA2/WPA3, включить или выключить раздачу.

- Настройки действуют только в текущей сессии, сохраняя системную конфигурацию хот-спота.
- Пароли не сохраняются и не журналируются. Чужая активная точка доступа не изменяется.
- Язык выбирается по языку интерфейса Windows: русский для русского, английский для остальных. Ручной выбор: `--lang ru` или `--lang en`.

## Требования

Windows 11 24H2+ (сборка 26100+), адаптер с поддержкой Mobile Hotspot / Wi-Fi Direct и активное подключение-источник. Диапазоны и защита зависят от драйвера. Windows может потребовать разрешение геолокации / Wi-Fi.

Для сборки: Visual Studio 2026 с компонентом разработки классических приложений на C++, Windows SDK 26100+ и CMake 4.2+.

## Сборка и запуск

```powershell
cmake --preset vs2026-x64
```

```powershell
cmake --build --preset release --parallel
```

```powershell
.\out\build\vs2026-x64\Release\WiFiStudio.exe
```
